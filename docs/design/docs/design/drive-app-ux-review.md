# 드라이브 앱 UX/UI 의견

**코드 확인.** 시작은 지도·오늘 길·보조 진입 두 개, 추천은 검은 텍스트 카드, 히스토리는 iOS 전용 작은 지도로 되어 있습니다. 상세에는 추천/회피 시간과 기록 진입이 남아 있습니다.[1] [2] [3] [4]

### 1. 한 줄
구조는 **쓰고 싶은 앱**에 가깝지만 지금은 “지도 위에 정보를 올린 앱”입니다. 말은 더 짧게, 그림은 **밝은 지도와 파란 한 줄**이 주인공이어야 합니다. 첨부 그림처럼 세 탭이 같은 선 굵기·여백을 쓰면 고르고, 타고, 남기는 흐름이 보입니다.

### 2. 시작 탭 그림
위에서 아래로 **지도 → 오늘 길의 이름·시작점/끝점·시간 → 버튼 하나**입니다. 지도 62%, 아래 패널 38%. 패널은 따뜻한 흰색, 버튼은 잉크 네이비·높이 56px·양옆 16px 여백이 적당합니다. 지도 선은 지금처럼 세 점으로 꺾이지 말고 실제 길 같은 연속선이어야 합니다. 안내문, ‘기록만 시작’, ‘다른 길 보기’, 위치 기준 보조문은 뺍니다.[1]

### 3. 추천 카드 그림
**위 지도 62% + 아래 정보 38%**의 세로 카드가 맞습니다. 지도에는 가는 파란 경로, 출발 채운 점, 끝 가는 원. 아래는 시간, 이름, 시작점→끝점 순이며 시간만 가장 큽니다. 카드 폭은 화면의 80%, 다음 카드 노출은 14~16%. Android 폴백은 검은 빈 화면 대신 아이보리 바탕의 옅은 도로 결 위에 파란 경로와 두 핀만 남긴 **정적 경로 그림**이어야 합니다. 현재의 검은 카드가 지도 배경이 되면 안 됩니다.[2]

### 4. 히스토리 한 줄
V1은 **스트라바식 작은 경로 그림**입니다. 단, 지도 타일이 아닌 정적 선 그림으로 통일합니다. 텍스트만보다 다시 찾을 길의 시각 기억이 남고 Android에서도 빈칸이 없습니다.[3]

### 5. 말

| 자리 | 단어 |
| --- | --- |
| 시작 버튼 | 이 길로 출발 |
| 시간 한 덩어리 | 왕복 1시간 |
| 상세 보조 버튼 | 경로 남기기 |

### 6. 하지 말 시각 5
큰 원형 진행 링, 지도 위 운동 수치 HUD, 거대한 플로팅 시작 버튼, 프로필·좋아요 피드, 주간 계획·연속 기록·배지. 운동 코칭 문법을 가져오면 이 앱의 한 호흡이 사라집니다.

### 7. 예/아니오

| 항목 | 답 |
| --- | --- |
| A. 시작 탭에서 기록 입구 완전 삭제 | **예** |
| B. 추천 카드에 인스타 출처 | **아니오** |
| C. 코스 이름 수식어(‘빛의 관문’) 유지 | **아니오** |
| D. 추천 카드 배경을 어두운 지도로 | **아니오** |

기록은 시작에서는 숨기고 상세의 ‘경로 남기기’로만 보조합니다. 출처는 상세 하단에만, 이름은 실제 장소·길의 고유명만 남깁니다. 결과 카드의 분 표기도 같은 시간 규칙으로 바꿉니다.[4] [5]

> 이 앱은 **예쁜 길을 한 번에 고르게 하는 지도**처럼 보여야 하고, **짧고 확신 있게 출발을 권하는 말**처럼 들려야 한다.
