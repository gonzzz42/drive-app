# 드라이브 앱 UI 정리 지시서

이 문서대로 기존 화면의 구성과 스타일만 바꾼다. 새 기능, 새 화면, 데이터·로직 변경은 하지 않는다.

## 0. 범위와 규칙

- 대상 파일: `app/(tabs)/_layout.tsx`, `app/(tabs)/index.tsx`, `app/(tabs)/browse.tsx`, `app/(tabs)/history.tsx`, `app/course/[id].tsx`, `app/record/[id].tsx`, `app/result/[tripId].tsx`
- 새 파일은 셋만: `src/ui/theme.ts`, `src/ui/RouteSketch.tsx`, `src/lib/format.ts`
- 건드리지 않는 것: `data/`, `src/lib/courses.ts`, `src/lib/trips.ts`, `src/lib/navi.ts`, `src/lib/supabase.ts`, `src/lib/recommend.ts`(호출만 줄임, 수정 없음)
- 의존성 추가는 `react-native-svg` 하나만 (`npx expo install react-native-svg`). 아이콘은 `@expo/vector-icons`의 Ionicons. 폰트는 시스템 기본.
- 금지: 검색·필터, 피드, 배지·레벨, 페이스, 추천 이유, 감성 문구, 사진, 그라데이션, 그림자, 어두운 지도, 알약 버튼, 지도 위 떠 있는 둥근 버튼, 드래그 핸들, 페이지 점, 회색 바탕 위 흰 카드 반복
- 화면에 절대 쓰지 않는 문구: `약 N분`, `좋은 때`, `피할 때`, `지금 추천`, `평일 21시 이후`, `내 위치 기준`, `대략 강서 기준`, `기록만 시작`, `다른 길 보기`, `티맵`, `카카오맵`, `인증 카드를 남기려면…`
- `best_time`, `avoid_time`, `region`, `tags`는 화면에 표시하지 않는다.
- 작업 순서: theme → format → RouteSketch → _layout → index → browse → history → course → record → result. 화면마다 커밋 하나.

## 2. 공용 (`src/lib/format.ts`, `src/ui/RouteSketch.tsx`)

### format.ts

```
roundTripLabel(minutes)  // 예상 시간. 칸으로 말한다.
  isFinite 아니면 → null
  40 미만 → "왕복 {반올림한 분}분"
  40 이상 → halfHours = 2 + floor((min - 40) / 30)
            2 → "왕복 1시간", 3 → "왕복 1시간 반", 4 → "왕복 2시간", 5 → "왕복 2시간 반" …
durationLabel(ms)        // 기록된 시간. 실제로 말한다.
  60분 미만 → "58분", 그 이상 → "1시간 24분" (분이 0이면 "1시간")
distanceLabel(km)        // "12.4 km" (소수 한 자리, 띄어쓰기 있음)
dateLabel(ms)            // 히스토리 "9월 4일", 결과 카드 "2026.09.03"
```

`roundTripLabel`이 null이면 그 자리에 `distanceLabel`을 대신 쓴다.

### RouteSketch.tsx

정적 경로 그림. 지도 타일 없이 `react-native-svg`로 그린다. 추천 카드, 전체 코스 썸네일, 히스토리 썸네일, 결과 카드에 같은 컴포넌트를 쓴다.

- props: `points: LatLng[]`, `width`, `height`, `stroke?`(기본 3), `pins?`(기본 true)
- 바탕 `bg`, 테두리 0.5px `line`, 모서리는 부모가 정함
- 위경도를 상자에 정규화. 위아래·좌우 여백 16%, 비율 유지(가로세로 중 긴 쪽 기준)
- 선: `accent`, 끝·꺾임 둥글게
- 점이 4개 미만이면 실선 대신 점선(`strokeDasharray="1 8"`, 둥근 끝). 4개 이상이면 실선
- 시작 점: `accent` 채운 원 r5, 흰 테두리 2. 도착 점: `pinEnd` 채운 원 r5, 흰 테두리 2
- 점이 없고 시작·도착 좌표만 있으면 두 점만 찍는다. 아무것도 없으면 빈 바탕만

### 지도 (MapView는 시작 탭과 상세에서만)

- iOS: `userInterfaceStyle="light"`. Android: `customMapStyle`로 채도 낮은 밝은 지도 (`poi` off, `transit` off, geometry `saturation -70`, `lightness 10`, water `#DBE4EA`)
- `showsPointsOfInterest={false}`, `showsCompass={false}`, `toolbarEnabled={false}`
- 경로: `Polyline` `strokeColor=accent`, `strokeWidth 5`, `lineCap="round"`, `lineJoin="round"`. 점이 4개 미만이면 `lineDashPattern={[1, 10]}`
- 시작 마커: 커스텀 View(accent 원 12, 흰 테두리 2.5), `tracksViewChanges={false}`. 도착 마커: `pinColor={pinEnd}`. `title` 넣지 않음(말풍선 없음)
- `fitToCoordinates`는 코스(폴리라인 + 시작 + 도착)만 대상. 내 위치는 포함하지 않는다. `edgePadding` 40
- 시작 탭 지도는 터치 비활성(감싼 View에 `pointerEvents="none"`). 상세 지도는 핀치·이동 허용

## 3. 화면

### 탭바 `app/(tabs)/_layout.tsx`

- 세 탭 모두 `headerShown: false` (제목은 각 화면이 그림)
- 아이콘 + 글자. Ionicons: 시작 `location-outline`, 추천 `compass-outline`, 히스토리 `time-outline`. 글자 12
- 활성 `accent`, 비활성 `text2`. 탭바 배경 `surface`, 위쪽 0.5px `line`, 그림자 없음

### 시작 `app/(tabs)/index.tsx`

위에서 아래로 두 덩어리뿐.

1. 지도. 화면 맨 위(상태바 아래까지)부터. 탭바 위 영역의 60%
2. 패널. 40%. 배경 `surface`, 위쪽 모서리 20, 지도와 20 겹침, 안쪽 여백 20. 패널 안에 또 카드를 넣지 않는다

패널 내용, 이 순서 그대로:

- `오늘의 코스` 13 text2
- 코스명 28/700 ink
- `{start_name} → {end_name}` 16 text2
- `roundTripLabel(...)` 16/600 ink (null이면 `distanceLabel`)
- 버튼 `길찾기` — 동작은 지금과 같음 (`openFirst(naviUrls(startTarget(course)))`)

코스명·구간 줄을 누르면 `/course/{id}`로 이동한다. 그 밖의 글, 링크, 안내문은 없다. `reasonFor`는 호출하지 않는다.

### 추천 `app/(tabs)/browse.tsx`

- 맨 위 제목 `추천` 22/700, 안전영역 아래 여백 20
- 가로 카드 (`recommendCourses` 결과, 최대 5): 카드 폭 = 화면 폭의 78%, 왼쪽 여백 20, 카드 간격 12, `snapToInterval`. 다음 카드가 약 15% 보여야 한다
  - 카드: `surface`, 모서리 16, 0.5px `line`, 그림자 없음
  - 위: `RouteSketch` 높이 = 카드 폭 × 0.6
  - 아래(여백 16): 코스명 18/700 → 구간 14 text2 → 왕복 시간 16/600 ink
  - 누르면 상세
- 그 아래 제목 `전체 코스` 18/700, 그 밑 모든 코스를 평평한 행으로:
  - `RouteSketch` 56×56 모서리 12 → 코스명 16/600 + 구간 13 text2 → `chevron-forward` 18 text2
  - 행 사이 0.5px `line`. 카드로 감싸지 않는다. 누르면 상세
- 없애는 것: `내 위치 기준` 힌트, 검은 카드, `약 N분`, 이유 줄, `더보기`, 페이지 점

### 히스토리 `app/(tabs)/history.tsx`

- 제목 `히스토리` 22/700
- 최신순 행. 카드 아니고 0.5px `line`으로만 구분, 행 세로 여백 16
  - 왼쪽: 코스명 18/700 → `{dateLabel} · {distanceLabel} · {durationLabel}` 14 text2 (예: `9월 4일 · 12.4 km · 58분`)
  - 오른쪽: `RouteSketch` 72×72 모서리 12. 기록 좌표가 있으면 그것, 없으면 코스 폴리라인
  - 누르면 `/result/{tripId}`
- 기존 `MiniMap`(MapView)과 `N회` 배지는 삭제. 행에 아이콘 없음
- 기록이 없으면 가운데 한 줄 `아직 기록이 없습니다` 15 text2

### 상세 `app/course/[id].tsx`

- 헤더: 투명, 뒤로가기만. 제목 없음(코스명은 본문에만)
- 지도: 화면 높이의 45~50%, 맨 위부터. 핀치·이동 허용. 폴리라인이 없으면 지도 영역을 아예 접는다 (`경로 좌표가 아직 없는…` 문구 삭제)
- 글(여백 20): 코스명 26/700 → `{roundTripLabel} · {distanceLabel}` 16/600 ink → 구간 15 text2 → 출처가 있을 때만 `출처 · {이름}` 13 text2 (한 줄, 이 줄 자체가 링크)
- 하단 고정(안전영역 포함): 버튼 `길찾기` (동작 지금과 같음) → 8 아래 보조 버튼 `경로 남기기` (`/record/{id}`)
- 없애는 것: `추천 시간`, `피할 시간`, 지역명, 안내문, 버튼 부제, `기록만 시작`, `원본 글 보기` 별도 줄

### 기록 `app/record/[id].tsx`

- 배경 `bg`. 위: 코스명 18/600 ink 가운데 정렬
- 가운데: `기록 중` 14 text2 → 경과 시간 64/700 ink(tabular-nums)
- 아래: 버튼 `종료` (저장 중엔 `저장 중…`). 다른 화면과 같은 파란 버튼
- `기록한 위치 N개` 삭제. 권한 없음 문구는 유지하되 글자색 `danger` 14, 배경 없음

### 결과 `app/result/[tripId].tsx`

- 카드(캡처 대상, `react-native-view-shot` 그대로): 배경 `bg`, 모서리 20, 여백 24, 비율 4:5
  - `밤 드라이브` / `낮 드라이브` 14 text2 (기존 `isNight` 로직)
  - `RouteSketch` 가로 꽉, 높이 = 카드 높이의 50%, 선 굵기 4
  - 코스명 28/700 ink
  - `{distanceLabel} · {durationLabel}` 20/600 ink
  - `{dateLabel}` 14 text2, 그 옆에 `완주`/`미완주` 14 text2 (초록·빨강 없음, 기존 판정 로직 유지)
- 카드 아래 버튼 두 개 나란히(높이 48): `저장` (테두리 0.5px `line`, 글자 ink) · `공유` (accent, 흰 글자). 동작은 지금과 같음
- 맨 아래 보조 버튼 `홈으로`
- 없애는 것: `코스 겹침 N% · 기록한 위치 N개`, 서버 저장 안내 문구, `코스 선으로 저장` 버튼. 업로드 로직은 호출만 유지하고 화면에 표시하지 않는다

## 5. 검증

- `npx tsc --noEmit` 통과
- iOS 시뮬레이터와 Android Expo Go에서 여섯 화면 모두 확인. Android에서 검은 영역이 한 군데도 없어야 한다 (카드·썸네일·결과 카드는 MapView를 쓰지 않으므로)
- `grep -rn "약 \|좋은 때\|피할 때\|기록만\|다른 길\|내 위치 기준\|티맵\|카카오맵" app/` 결과가 비어야 한다
- 각 화면에 파란색은 경로선·점·메인 버튼·활성 탭에만, 코랄은 도착 점에만, 빨강은 오류 문구에만 있어야 한다
