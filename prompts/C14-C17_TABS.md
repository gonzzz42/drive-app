# C14~C17 세 탭 (Claude Code용)

잠긴 결정 (바꾸지 마라)
- 탭 셋: 시작 / 추천 / 히스토리
- 시작: 오늘 길 1장 + 지도 + "이 길로 출발"(내비만, 시작점). 기록 자동 켜지 마.
- 추천: 가로 5장 + 더보기(검색 없음). 공식 코스만.
- 히스토리: 시간순 기록. 총 km 레벨 없음.
- 백그라운드 GPS, 피드, 하단 범용 기록 버튼, 자체 내비 만들지 마.

공통 머리말:

```
CLAUDE.md와 이 파일의 잠긴 결정을 지켜라.
한국어 UI.
한 단계만 하고 멈춰라.
끝나면 바꾼 파일, 폰에서 눌러볼 순서, 아직 안 되는 것을 한국어로.
커밋은 내가 하라고 할 때만.
```

파일: app/_layout.tsx, app/(tabs)/_layout.tsx 신설, 기존 홈/도감을 탭으로 옮긴다.

- expo-router Tabs 3개
  - 시작 → app/(tabs)/index.tsx
  - 추천 → app/(tabs)/browse.tsx
  - 히스토리 → app/(tabs)/history.tsx
- course/[id], record/[id], result/[tripId] 는 탭 밖 Stack으로 유지
- 기존 app/index.tsx, app/album.tsx 내용은 잠시 탭 화면으로 옮겨도 된다. 이 단계에서 UI를 새로 예쁘게 만들지 마라.
- 하단 탭 라벨: 시작 / 추천 / 히스토리
- 새 패키지는 expo-router 탭에 필요한 것만.

폰: 아래 세 탭이 보이고 각각 들어가기만 하면 성공.

## C15. 시작 탭

파일: app/(tabs)/index.tsx, src/lib/recommend.ts, src/lib/navi.ts

- 화면을 열면 오늘 길 1개를 자동 고른다.
  조건: start_lat/lng 있음, distance_km > 0, 왕복 추정 90분 이하 우선, 밤이면 태그 '밤' 가산.
  해당 없으면 다음 후보. 하나도 없으면 지도+ "추천에서 길을 고르세요" + 추천 탭으로 가는 버튼. 큰 출발 버튼은 비활성.
- 지도: 내 위치(있으면), 코스 polyline, 시작 핀. 다른 코스 핀 넣지 마.
- 카드 한 줄: 이름, 약 N분, best_time/avoid_time을 변환한 아는 이유. "지금 추천" 단정 금지.
- 검정 큰 버튼: "이 길로 출발"
  동작: 티맵(또는 카카오)을 코스 시작점으로 연다. 기록 화면으로 이동하지 마.
- 작은 텍스트: "기록만 시작" → /record/[id]
- 작은 링크: "다른 길 보기" → 추천 탭
- 한 줄 안내: "인증 카드를 남기려면 출발 전에 기록을 켜 두세요."
- 홈에 코스 리스트, 도감 큰 버튼 넣지 마.

## C16. 추천 탭

파일: app/(tabs)/browse.tsx, data/courses.json, src/lib/courses.ts

- courses.json 각 코스에 필드 추가해도 된다:
  featured: boolean (메인 선반)
  source_name, source_url (원본 계정/글, 없어도 됨)
- 가로 스크롤 카드 최대 5장. featured true 인 공식 코스만.
  featured가 하나도 없으면 좌표+거리 있는 코스를 가까운 순으로 최대 5.
  빈 칸 채우지 마. 3개면 3장.
- 카드: 이름, 약 N분, 아는 이유 한 줄. 다음 카드가 살짝 보이게(폭 약 80%).
- 카드 탭 → /course/[id]
- 아래 "더보기": 공식 코스 전체 리스트(이름+분). 검색창 만들지 마. 필터는 나중에.
- 기록 버튼, 도장, 완주율 이 탭에 넣지 마.
- 내 코스 구분 넣지 마.

## C17. 히스토리 탭 + 상세 출처

파일: app/(tabs)/history.tsx, app/course/[id].tsx

히스토리:
- listLocalTrips() 시간순(최신 위)
- 행: 코스명, km, 분, 날짜, 가능하면 아주 작은 MapView 궤적(점 2개 이상).
  Android에서 맵이 검으면 맵 없이 숫자만.
- 행 탭 → /result/[tripId]
- 같은 코스 횟수가 있으면 "3회" 정도만. 완주 N/전체 M, 미주행 목록, 월 km 그래프, 레벨 넣지 마.
- 기록 0개면 "아직 탄 길이 없습니다"

상세 course/[id]:
- 주 버튼은 내비(시작점). "기록만 시작"은 보조.
- source_url 있으면 "원본 글 보기" 링크.

결과 화면은 이 단계에서 큰 수술하지 마라. C13이 안 되어 있으면 판정/서버 문구만 __DEV__로 숨겨도 된다.
